# Rahul Verma | Full-Stack Developer Portfolio

Welcome to the source code of my personal developer portfolio. This single-page application is designed to showcase my engineering skills, featured projects, academic background, and certifications.

## Overview

The portfolio is built with a minimalist, high-performance architecture. It focuses on clean typography, responsive grid layouts, and seamless animations to provide an excellent user experience. 

Key technical highlights include:
- A custom interactive terminal (mock CLI)
- Smooth scroll spying and dynamic navigation
- Framer Motion page transitions and layout animations
- Cloudinary-optimized image delivery (WebP)

## Tech Stack

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Local Development

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/rahulkrvermaa/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
